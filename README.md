# PRO-PITCH OMEGA V10 — Private Chrome Edition

This is the **website + Python backend** version for private personal use from Chrome's Android home-screen shortcut. No Android APK and no Play Store publishing required.

Read **START_HERE.md** to activate the hosted website. `render.yaml` selects the Free plan, requests credentials only from Render (not the repository), and enables private password login. The `site/` folder contains the dashboard and PWA manifest; `server/` runs the V10 research engine and provider connector. The API displays only verified connected-provider data, not fabricated picks. `tests/` contains the automated checks.

**Not deployed yet.** It needs the account owner to authorize hosting and supply the football-data.org key securely in Render.
